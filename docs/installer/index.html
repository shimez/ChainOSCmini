ChainOSCmini

Chain DualKeyへファームウェアをブラウザーからインストールできます。

Stable version 1.0.1

ChainOSCminiは個人が開発する非公式プロジェクトです。M5Stack Technology Co., Ltd.による公式製品ではありません。

Web Installer

Chain DualKeyをデータ通信対応USBケーブルでPCへ接続し、下のボタンからシリアルポートを選択してください。

このブラウザーはWeb Serialに対応していません。デスクトップ版ChromeまたはEdgeを使用してください。
  1. Chain DualKeyの電源スイッチを中央のOFF/USBにします。
  2. 「Install ChainOSCmini」を押し、Chain DualKeyのシリアルポートを選びます。
  3. 画面の案内に従ってインストールを完了します。
ポートが表示されない場合は、KEY1を押しながらUSBケーブルを接続してダウンロードモードを試してください。
再インストールや消去を行う前に、必要な設定をJSONへバックアップしてください。

Quick Installation Guide (English)

Use desktop Google Chrome or Microsoft Edge.

  1. Set the Chain DualKey power switch to the center OFF/USB position and connect it with a USB cable that supports data.
  2. Select Install ChainOSCmini and choose the Chain DualKey serial port.
  3. Follow the on-screen instructions to complete the installation.
If the port is not listed, hold KEY1 while reconnecting the USB cable to enter download mode.
Before reinstalling or erasing the device, back up important settings as JSON from the Web UI.
